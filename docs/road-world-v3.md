# Road World V3 quality pass

## Inspection findings

- The tile builder ignored OSM `width`, `lanes`, and `surface` even though the extraction pipeline could preserve them. It assigned fixed widths by class; residential and unclassified ways were 6 m before shoulders and terrain blending.
- The rendered residential corridor added 0.7 m shoulders and a 1.2 m terrain ribbon on each side. Separate uniform strips made the engineered corridor read as several broad ribbons.
- Asphalt was one class tint, shoulder/earth were flat shared colors, and major road paint was bright, long, and generated by class without a source marking opt-out.
- Junctions used a convex hull apron and clipped covered strips. Existing tests checked render/query/collider agreement, but there were no checked-in screenshots or captures to diagnose particular live intersections.
- Shoulder geometry used the carriageway crown profile all the way to its outer edge, leaving an abrupt visual cross-section. Existing mesh-part surface tags are now retained in rendered queries, including after junction clipping.
- Street World already owns the broader roadside environment (drains, walkways and furniture). Road World sidewalks remain source opt-in; no duplicate drains or walks were added.

## Changes

- Added OSM width preservation during extraction and width provenance, lane count, surface, one-way and junction identity to generated road tile data. Plausible explicit OSM widths (2.2–32 m) win; lane counts use deterministic class lane widths; otherwise class defaults apply. Existing OSM way IDs and centerlines are retained.
- Tightened class defaults and reduced immediate engineered edge/blend widths. Residential roads have no formal paint; service/living streets remain narrow and unmarked. Motorway/trunk/primary/secondary keep clearer width, tone and paint hierarchy.
- Added subtle deterministic road/shoulder tint variation and more restrained, shorter class/source-gated markings. LOW continues to retain road/collision shape and drops edge paint.
- Added a slight crossfall across the immediate engineered shoulder and preserved rendered mesh-part surface labels in queries. Visible geometry, WorldSurface query, terrain clipping and colliders still use the same triangles.
- Added DEV-only `?roadDebug=1` summary HUD for streamed tile/segment counts, road/junction/paint triangles, draw calls, terrain triangles, class counts and worker/clipping/upload/collider timings.
- No routing logic, vehicle ownership/economy, World Asset Delivery, buildings, or Street World generation was changed.
