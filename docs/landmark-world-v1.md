# Landmark World V1 and world safety

## Delivered behavior

Three source-derived Ibadan treatments share CityMap identities: Cocoa House, University College Hospital (UCH), and Agodi Gardens. LAUTECH Senate Building has registry/map integration; Ogbomoso is not enabled for 3D travel. Architecture and vegetation are procedural interpretations, not surveyed replicas. There are no imported landmark GLBs in this delivery.

| Landmark | Existing identity | Shared map/world X, Z (metres) | Treatment |
| --- | --- | --- | --- |
| Cocoa House | `osm:way:1283222827` | -1976, 904 | B: source footprint, source 105 m height, facade detail |
| UCH | `osm:way:82467201` | 615, -655 | C: source campus buildings with institutional treatment |
| Agodi Gardens | `osm:way:373337181` | 431, -1212 | B: source park polygon, terrain-conforming lawn and vegetation |
| LAUTECH Senate Building | `osm:way:1245094788` | 40868, -85186 | C definition; Ogbomoso remains map/registry only |

Coordinates and identities come from the existing local-PBF CityMap extraction. The map manifest records the extracted source SHA256 `3c67aebd88781bc53a26d1cb24546b05306e22232196f5cc3d824180cff02f94` for Ibadan. No landmark coordinates were invented or moved toward spawn. `LandmarkIdentity.js` supplies shared model identity, region, coordinates, source status and future venue/interaction placeholders. `build-landmarks.mjs` derives compact world registries from the existing map source, with exact source identities.

UCH is a campus area, not a building row. The generator associates 498 source building identities whose footprint centers lie inside its actual source polygon, excluding holes. Each retains its own source geometry and collision record while referring to the campus's one landmark identity. The generator does not substitute an arbitrary building near the campus pin.

## Safety findings and protection

The pre-existing numeric terrain sampler clamps coordinates to a finite terrain plane's edges. Roads, map data and buildings extend beyond the initial 700 m patch and final 1400 m terrain square. Thus a finite height query previously remained available outside visible terrain and collider coverage. The regression test reproduces this phantom-floor query. This is a confirmed failure path; the original reported live incident had no trace, so its exact sequence cannot be established retrospectively.

`WorldSurface.coverageAt()` reports actual loaded bounds, rendered road/terrain coverage and the corresponding collider owner. Numeric height sampling remains compatible with existing geometry generation; gameplay validity uses the explicit coverage check.

Protection includes:

- Validate and seed a safe grounded spawn before activating gameplay.
- Keep at most 32 runtime safe positions, spaced by movement, scoped to region and vehicle. Nothing is written to the server.
- Record safe positions only with a finite valid surface, collider coverage and grounded contact. Vehicle grounding checks wheel contacts.
- Recover when more than 12 m below the local surface; allow 1.5 seconds of missing surface/collider coverage before recovery. Legitimate airborne jumps on valid surfaces do not start that timeout.
- Prevent walking beyond the loaded patch, with a normal boundary notice near the edge. A driven vehicle crossing the inset boundary is restored with the player; linear/angular velocity is reset and the chassis is placed upright.
- Revalidate history before using it. If every saved surface is unavailable, hold the last grounded pose while streaming retries, instead of continuing into void.
- Prepare neighboring 1400 m Ibadan patches near a patch edge. Replacement terrain, roads and colliders are ready before the previous owner is released. Failed loads retain the old patch and use a 15-second retry backoff.
- Retire old road owners so late fetches and worker continuations cannot reinstall removed geometry or colliders. Building foundations and street inputs are invalidated when terrain changes.

Travel patches stay inside the Ibadan source region bounds. Loaded-patch bounds are the authoritative playable coverage at any instant. This does not enable inter-city travel. The existing rendered road dataset has 30 core tiles; outside those tiles terrain and buildings can stream, but additional road meshes have not been generated by this change.

## Rendering, streaming and assets

Building overrides use the existing `BuildingOverrideRegistry` and source building tiles. A missing, null or failed override retains the ordinary procedural building. Region checks prevent a registered source identity from rendering in another region. LOD decisions remain Building World's existing distance/hysteresis rules, with shorter LOW ranges. Campus components batch by tile, landmark, LOD and material, rather than producing a draw call per facade. Far landmark buildings use only source massing. Decorative model triangles do not enter physics; the existing simplified footprint collision batches remain authoritative. Park vegetation has no additional colliders.

Area landmarks use the same override registry, with bounded near-player activation and explicit disposal of geometry and materials. CityMap never imports the landmark model or GLB loader. The world fetches a separate compact derived registry only after terrain promotion, outside the first-playable path. Far models unload with building tiles or the area-landmark distance limit. Destination selection keeps the same source coordinates and straight-line feedback.

`LandmarkAssetLoader.js` is the Tier A intake/loading foundation. It requires a successful validation report, checks byte size and SHA256 before decoding, imports GLTFLoader lazily, and exposes fetch/decode metrics and disposal. No Tier A model is registered yet. The asset validator checks GLB framing, embedded resources, triangle/material/texture budgets, and the scale/orientation/pivot/LOD/collision contract. Embedded texture sizes are inspected from image bytes. Physical dimensions, orientation and pivot still require visual review; exporter declarations alone do not prove their correctness.

UCH totals include the simultaneously loaded FAR/MEDIUM/NEAR components of a large campus; they are not the cost of one full-detail mesh. Park ground clips the actual terrain triangles to the source polygon, including holes, rather than interpolating an incompatible coarse surface. Its triangle count can change at terrain patch boundaries. Shared footprint colliders must not be summed once per landmark draw group. The initial normal/low loaded-ring samples accumulated 129.2/102.7 ms CPU model generation and 117.6/102.7 ms batching across many incremental tile builds; these are cumulative workload figures, not a single-frame pause. Park generation accumulated 63 ms across the final visits, LOD changes and terrain replacements. The registry assets are 9,323 bytes for Ibadan and 443 bytes for the inactive Ogbomoso record. The deferred model code bundle is 5.25 kB (2.30 kB gzip). There are no landmark texture assets.

Default intake limits: 20 MiB file size, 100,000 triangles, 2048 px texture dimensions, 64 MiB estimated RGBA mipmapped texture memory, and 32 materials. Reports include limits, errors and the source-file hash. No imported asset means landmark GLB bytes, texture memory and GLB decode cost are zero for this phase. GPU geometry-upload timing is not available from the current instrumentation; CPU generation/batching, retained geometry bytes, loaded triangles and draw calls are exposed.

## Validation and artifacts

Run from the repository root:

```powershell
node pipeline/world/build-landmarks.mjs
node --test --test-concurrency=1 apps/client/test/*.test.mjs
npm.cmd run build:client
```

For a future imported asset:

```powershell
node pipeline/world/validate-landmark-asset.mjs model.glb contract.json report.json
```

The contract declares `metresPerUnit: 1`, `upAxis: "+Y"`, `forwardAxis: "+Z"`, `pivot: "ground-center"`, `lods: ["near", "medium", "far"]`, and a simplified `collision` representation. Each actual LOD asset must be validated separately.

DEV diagnostics: `?worldSafetyDebug=1` and `?landmarkDebug=1`. They expose surface/collider state, position, region, loaded bounds, last safe ground, recovery reason/count, loaded landmark IDs, source coordinates, LOD, geometry, draw calls, retained memory and shared collider ownership. Normal gameplay receives only the boundary notice.

Live scripts use an isolated Chrome debugging session on port 9222 and Vite on port 5175:

```powershell
node pipeline/world/validate-landmark-world.mjs
node pipeline/world/capture-landmarks.mjs
node pipeline/world/validate-world-safety-vehicle.mjs
```

Local artifacts are in `data/generated/landmark-world-v1/`: live measurements, per-view landmark statistics, NORMAL/LOW images, CityMap selection, player recovery, boundary handover, vehicle recovery, test output and build output. Capture movement uses DEV position placement through valid patches to exercise streaming, rather than claiming an uninterrupted keyboard-driven road journey.

All 110 client tests pass, including real terrain-triangle agreement for the park overlay, safe-history rules, jump tolerance, vehicle-scoped recovery, late road-worker retirement, region isolation, override fallback, campus batching, area load/unload and GLB admission budgets. The production client build passes. The final code-only production rebuild reused the already copied public assets (`copyPublicDir: false`); the earlier normal build copied the complete public directory successfully. The existing large-chunk warning for Three/Rapier remains.

The final live pass recorded first playable at 4.75 s NORMAL and 5.17 s LOW, with landmark registry requests starting around 14.35 s and 14.41 s respectively. The 9,323-byte Ibadan registry request took 12.2 / 24.9 ms. This was a local development run with existing caches, not a controlled production cold/warm comparison. Both modes recovered an injected below-world fall and promoted terrain from Z [-700, 700] to [-1400, 0]. The vehicle check recovered player/chassis together, returned an out-of-bounds player, and observed zero recoveries during a normal Space jump. The final artifacts are the authoritative per-view performance measurements.

Routing, interiors and NPC/business simulation remain deferred. CityMap stays lazy, first-playable startup has no landmark dependency, and ordinary source building streaming/collision ownership is retained.
